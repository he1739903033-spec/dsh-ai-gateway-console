# 配置参考

## 配置文件位置

按顺序查找，命中第一个：

1. 环境变量 `AIGW_CONFIG` 指向的文件
2. `~/.dsh/ai-gateway-console.json`（默认，安装脚本写这里）
3. `<插件目录>/config.json`（想把配置随仓库带走时用）

## 完整示例

```jsonc
{
  "console": {
    "host": "127.0.0.1",
    "port": 8330,
    "python": "",            // 留空 = 自动探测
    "autoStart": false       // dsh 启动时是否自动拉起控制台进程
  },
  "trae": {
    "base": "D:/tools/Trae2api-cn",
    "url": "http://127.0.0.1:8327",
    "key": "trae-gw-…",
    "startScript": "launch-all.vbs",
    "logDir": "logs"
  },
  "workbuddy": {
    "base": "D:/tools/workbuddy-gateway",
    "url": "http://127.0.0.1:8317",
    "key": "…",
    "startScript": "launch-gateway.vbs",
    "statusFile": "workbuddy-status.json",
    "configFile": "config.json",
    "logDir": "logs"
  },
  "hub": {
    "base": "D:/tools/workbuddy2api-hub",
    "url": "http://127.0.0.1:8788"
  },
  "controllers": [
    {
      "id": "watchdog",
      "name": "服务守护",
      "desc": "网关 + Hub 的看门狗，30 秒内拉起掉线服务",
      "mutex": "Local\\WorkBuddyServiceWatchdog",
      "script": "guard-workbuddy-gateway.ps1",
      "log": "watchdog.log"
    }
  ]
}
```

## 字段说明

### console

| 字段 | 默认 | 说明 |
|---|---|---|
| `host` | `127.0.0.1` | 控制台监听地址，别改成 `0.0.0.0`（那会暴露到局域网） |
| `port` | `8330` | 端口 |
| `python` | 空 | Python 可执行文件绝对路径。留空时按 `AIGW_PYTHON` → PATH 上的 `python`/`python3`/`py` → 常见安装位置 依次找 |
| `autoStart` | `false` | dsh 启动后是否自动拉起控制台进程 |

### trae / workbuddy / hub

| 字段 | 说明 |
|---|---|
| `base` | 项目根目录。留空时走自动探测 |
| `url` | 服务地址。端口变了就改这里 |
| `key` | 网关密钥。留空时尝试从项目文件里读（Trae 抓 `trae-gw-<hex>`，WorkBuddy 读 `GATEWAY_KEY`） |
| `startScript` | 启动脚本名（相对 `base`）。默认 `launch-all.vbs` / `launch-gateway.vbs` |
| `logDir` | 日志目录名（相对 `base`），默认 `logs` |
| `statusFile` | WorkBuddy 独有：网关状态快照文件名 |
| `configFile` | WorkBuddy 独有：网关配置文件（模型白名单 / 站点绑定） |

`base` 填了之后，以下派生路径自动算出来，不用手写：
`trae.logFile`、`workbuddy.statusPath`、`workbuddy.configPath`、`workbuddy.logDirPath`。

### controllers

数组，每一项描述一个无端口的常驻控制器：

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，同时作为日志路由的 `src` 参数 |
| `name` | 显示名 |
| `desc` | 一句话说明 |
| `mutex` | 单实例互斥体全名（`Local\...`）。**存活判据** |
| `script` | 启动脚本名（相对 `workbuddy.base`），仅供参考显示 |
| `log` | 日志文件名（相对 `workbuddy.logDir`） |

整段可以替换 —— 你有几个控制器、叫什么名字，这里就写几条。

## 环境变量

环境变量优先级高于配置文件，适合临时覆盖而不动文件。

| 变量 | 作用 |
|---|---|
| `AIGW_CONFIG` | 指定配置文件路径 |
| `AIGW_TRAE_BASE` / `AIGW_WB_BASE` / `AIGW_HUB_BASE` | 组件根目录 |
| `AIGW_TRAE_URL` / `AIGW_WB_URL` / `AIGW_HUB_URL` | 服务地址 |
| `AIGW_TRAE_KEY` / `AIGW_WB_KEY` | 网关密钥 |
| `AIGW_CONSOLE_PORT` | 控制台端口 |
| `AIGW_PYTHON` | Python 可执行文件 |
| `AIGW_SEARCH_ROOTS` | 追加搜索根，多个用 `;` 分隔（Windows） |

## 路径解析顺序

对每个组件，按三级策略解析 `base`：

1. 配置文件里的 `*.base`
2. 环境变量
3. 自动探测：
   - **常见位置**：家目录下的 `Tools` / `tools` / `Documents` / `Desktop` / `Downloads` / `opt`、
     各盘符的 `\Tools` 与根目录，再加上 `AIGW_SEARCH_ROOTS` 追加的
   - **特征文件**：要求标志文件全部存在，不只看目录名

   | 组件 | 标志物 |
   |---|---|
   | Trae | `web_login.py` + `src/main.py` |
   | WorkBuddy | `workbuddy-gateway.exe` |
   | Hub | `wb-proxy/wb_proxy.py` |

   所以目录叫 `trae-relay` 还是 `Trae2api-cn` 都能认出来。

## 插件侧开关

这三个不在配置文件里，在 `cordis.patch.yml` 的插件 `config` 段（改完要重启 DSH）：

```yaml
- insert:
    - id: ai-gateway-console
      name: 'dsh-ai-gateway-console'
      config:
        consolePort: 8330
        autoStart: false
        statusTtlMs: 5000
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `consolePort` | 8330 | 覆盖配置文件里的 `console.port` |
| `autoStart` | false | 覆盖配置文件里的 `console.autoStart` |
| `statusTtlMs` | 5000 | 快照缓存时长。状态页 8 秒刷一次，缓存能避免每次刷新都打上游 |

## 只读接口

给脚本或别的工具用：

```powershell
# 聚合快照（deep=1 才探控制器互斥体，约 0.5 秒）
curl.exe -s "http://127.0.0.1:<dsh端口>/ai-gateway/status?deep=1"

# 当前配置 + 体检
curl.exe -s "http://127.0.0.1:<dsh端口>/ai-gateway/config"

# 日志（src 取 trae / wb / 控制器 id）
curl.exe -s "http://127.0.0.1:<dsh端口>/ai-gateway/logs?src=wb&n=200"

# 动作
curl.exe -s -X POST "http://127.0.0.1:<dsh端口>/ai-gateway/action" `
  -H "Content-Type: application/json" -d '{\"action\":\"start-console\"}'
```

可用动作：`start-console` / `stop-console` / `start-trae` / `start-wb` / `start-all` /
`reload-config` / `controllers`。

所有接口都校验 `Host` 头必须是回环地址 —— 局域网内别的机器访问会被 403。
